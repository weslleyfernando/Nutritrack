# NutriTrack

O NutriTrack é uma aplicação desenvolvida para auxiliar usuários no acompanhamento da alimentação e no gerenciamento de informações nutricionais. O objetivo é oferecer uma forma prática de registrar refeições e acompanhar hábitos alimentares.

# Funcionalidades

- Cadastro e login de usuários
- Registro de refeições
- Consulta do histórico alimentar
- Cadastro de alimentos
- Visualização de informações nutricionais
- Interface intuitiva e responsiva

# Tecnologias Utilizadas

- PostgreSQL + Drizzle ORM
- OpenAPI 3.1 + Orval
- CSS,  React 18, Vite, TypeScript, Tailwind, shadcn/ui
- Node.js 24, Express 5, TypeScript
- Git e GitHub

## 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/nutritrack.git
```

2. Entre na pasta do projeto:

```bash
cd nutritrack
```

3. Instale as dependências:

```bash
npm install
```

4. Execute a aplicação:

```bash
npm start
```
